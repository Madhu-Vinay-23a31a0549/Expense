# Expense Tracker Dashboard

A web-based Expense Tracker Dashboard built using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

This project helps users record, manage, and analyze their daily expenses. It includes expense CRUD operations, dashboard summaries, charts, reports, and export options.

## Features

- User-friendly dashboard
- Add, view, edit, and delete expenses
- Categorize expenses
- Monthly expense summary
- Bar chart and line chart reports
- Top categories list
- PDF report download
- Responsive design
- MySQL database integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Node.js
- Express.js

### Database
- MySQL
